### 关于第 1 步的安全

**小米账号密码不要发进对话或微信。** 做法：脚本在 mini 上跑，你**在 mini 跟前输一次**。

### 关于第 3 步

米家 App → 点进网关 → 设置 → **「局域网通信协议」** → 开启。开了之后我能本地读到所有 Zigbee 子设备。

## 四、已经能看出的方案骨架

```
15 台 Wi-Fi 设备  →  提 token  →  本地直连（不依赖小米云）
Zigbee 子设备     →  问网关（局域网协议）→ 本地
小爱音箱 ×2       →  可做语音入口
TCL 85Q10G        →  AirPlay / 投屏
追觅扫地机        →  地图 + 实时位置（做 3D 的素材）
IMILAB 摄像头     →  取流做自定义 AI（要看是否开放 RTSP）
博世家电          →  看是否支持接入（可能只能走各自 App）
```

**15 台里最值得先做的**：灯和插座（响应快、效果直观）。
