## 0 · 与宪章的关系

VI 不是独立的审美选择，而是**品味的物质化**。宪章第六条六条品味逐条对应视觉后果：

| 品味 | 视觉后果 |
|---|---|
| 诚实 | 状态不靠颜色单独表达；未接入就是灰字说明；推断用虚线 + 文字 |
| 安静 | 无红点、无夺目动效、无装饰性渐变；信息在场但不喧哗 |
| 克制 | 一个视图一个主色按钮；不新增颜色、图标、容器 |
| 有重量 | 回执与撤销常驻；过渡 120–220ms、位移 ≤8px |
| 耐用 | 系统字体、可编辑 SVG、CSS 变量；不绑死宿主实现 |
| 精致 | 同一控件唯一实现；同层级同字阶；间距只用标尺；四态齐全 |

**v0.1 评估结论（本版已补齐）**：原「纸上秩序」VI 对第六条（品味）符合度高，但对宪章第三条（判断一等公民）与第四条（建议闭环）**没有对应视觉语言** —— 那是"事务型工作台"的 VI。本版通过 §9 与增补条款 V1–V3 补齐，并把 V9（精致）纳入门禁。

## 1 · 标识

- 标记名「连接之窗」：52 × 52 网格，主线宽 2.4。左下开放边界＝工作区；折线从节点向右上展开＝工作推进与关系延展。
- 安全区 ≥ 8/52 标识宽；数字端最小 24px；字标 24px / 500；标识与字标间距 12px。
- 四态资产：标准墨色、品牌蓝、反白、应用图标（圆角 13/52 蓝色底）。
- 禁止：拉伸、旋转、渐变填充、发光、加阴影。
- 正式发布前需完成名称/商标检索；生产物料字标需在实际字体环境转曲。

## 2 · 色彩

**唯一色值来源**：`design-system/tokens.json` / `tokens.css`。**代码里不得出现字面色值。**

| 变量 | 色值 | 用途 |
|---|---|---|
| `--ws-paper` | `#F8F9F7` | 页面底 |
| `--ws-surface` | `#FFFFFF` | 内容容器 |
| `--ws-ink` | `#252A31` | 正文 |
| `--ws-muted` | `#626C78` | 次级 / 辅助 |
| `--ws-line` | `#DCE1E5` | 分隔线 |
| `--ws-action` | `#315ED0` | 行动与聚焦（唯一主色） |
| `--ws-action-soft` | `#EDF2FF` | 操作区底 |
| `--ws-success` / `-soft` | `#28735B` / `#EDF6F1` | 已完成 |
| `--ws-warning` / `-soft` | `#8A601D` / `#FBF4E6` | 等待 / 不确定性 / 限制 |
| `--ws-danger` / `-soft` | `#B33F44` / `#FBEFF0` | 失败 |
| `--ws-knowledge` / `-soft` | `#7555A1` / `#F3EFF8` | AI 推导 / 记忆 / 知识 |

**使用规则**
- 蓝色只承担**行动与聚焦**；其余颜色只表达**真实状态或对象类型**。
- **颜色不得单独承担判断**：绿点必配"已完成"，赭色必配原因文字，虚线必配"AI 判断"。
- 常规页面配比建议：中性空间 ≈85%、文字与线条 ≈10%、行动色 ≈5%。
- **新增颜色必须对应一个全新的真实状态**，且必须同时有文字与符号（V5）。

## 3 · 字体与排版

- 字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`；数据与路径用系统等宽。**不引入外部字体文件**（耐用性）。
- 字阶（唯一一套，不得新增字号）：

| 层级 | 字号/行高 | 字重 |
|---|---|---|
| 数据 | 32 / 40 | 550，等宽数字 |
| 弹窗标题 | 22 / 30 | 600 |
| 模块标题 | 18 / 26 | 600 |
| 小标题 / 标签 | 13–15 | 600 |
| 正文 | 14 / 22 | 400 |
| 辅助 | 12 / 18 | 400 |
| 最小 | 11（仅时间、坐标等非关键信息） | 400 |

- 数字一律 `font-variant-numeric: tabular-nums`。
- 产品页**不设大号宣传句**；页头＝面包屑 + 一行小字提示。
- 中英文之间留空；中文标点用全角；长名称有确定换行规则（默认最多两行 + 可展开全文）。

## 4 · 间距、圆角、层

- **间距标尺**（唯一）：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。**标尺外的像素值不允许出现。**
- 圆角：控件 8 · 内容容器 12 · 居中弹窗 20 · 标签 999。
- 边框 1px；**只有浮层使用明显阴影**，其余靠边框与留白分层。
- 密度：常规行 48 · 紧凑行 40 · 移动点击区 ≥ 44 × 44。
- 布局：侧栏 204 · 顶栏 72–80 · 页边距 32 · 弹窗宽 760（最高 88vh/88dvh）· 桌面 12 栏栏间距 16。
- 一块内容**最多两层容器嵌套**。

## 5 · 图标与简笔画

**图标**：24 × 24 网格 · 1.6px 线宽 · 圆端点圆转角 · 显示 16/20/24。16px 可省略非关键细节。选中态由底色 + 文字补充，不只把线条加粗。**禁止用 emoji 当图标**（V9）。

**简笔画**：240 × 160 母版 · 2px 线宽 · 墨色 + 1 个蓝色强调 · 留白 ≥50%。功能页每屏最多一幅；建议宽 96–180px，空态 160–220px。禁止表情包、拟人机器人、复杂透视、随机抖线、盖住数据。

**新增准入**（V5）：新图标必须证明现有图标无法表达，并登记入册。

## 6 · 组件唯一来源（V9 精致）

**每个控件全站只有一个实现。** 已登记清单（新增须登记，未登记即门禁失败）：

| 组件 | 唯一实现要求 |
|---|---|
| 按钮 | 三档：主（工作蓝实底，一视图仅一个）/ 次（白底描边）/ 文字。四态齐全 |
| 输入、下拉、文本域 | 统一高度、边框色、聚焦环 3px、错误态在字段旁 |
| 居中弹窗 | 一套：标题行＝「类型 · 记录名」+ 关闭；正文滚动区；动作区 ≤2 处；Escape；焦点锁定与恢复；背景不可操作；未保存保护 |
| 卡片 | 一套圆角 12 + 边框 + 内边距（20/24） |
| 列表行 / 看板卡 | 行高 48 / 40，图标 + 主文字 + 辅助 + 右侧计数 |
| 空态 | 简笔画 + 一句状态 + 一个下一步按钮 |
| 反馈条 | 成功 / 等待 / 失败 / 未接入 四种，位置固定 |
| 标签 | 圆角 999，色 + 文字 |
| 撤销条 | 左下常驻「已保存 · 撤销」 |

**四态齐全**：默认 / 悬停 / 聚焦 / 禁用。**没做状态就不算做完。**

## 7 · 状态与反馈语言

| 状态 | 视觉 | 文字规则 |
|---|---|---|
| 进行中 | 静态骨架保留布局；超 1 秒才提示"正在读取" | 不显示假百分比 |
| 已完成 | `success` 点/底 + 文字 | 有真实回执才可说"已保存" |
| 等待 | `warning` 文字 | 写明等谁/等什么；没写就"原因未记录" |
| 失败 | `danger` + 一句人话 + 一个可点下一步 | 禁止 JSON、禁止技术堆栈 |
| 未接入 | 灰字说明 | 不给做不到的按钮 |
| 推断 · 待核对 | `knowledge` + 虚线 + 「AI 判断」 | 区分"对方自述""未经第三方验证" |

**即时生效 ≠ 乐观 UI**：点击立刻响应（丝滑）允许；收到回执前显示"已保存"禁止。状态文字如实走「保存中… → 已保存」；失败回滚并说明。

## 8 · 判断与建议的视觉语言（V1–V3，本版新增）

**V1 来源三态** —— 任何信息必须一眼可辨：

| 来源 | 视觉 |
|---|---|
| 你说的 | 墨色实边 |
| AI 推的 | `knowledge` 紫 + 虚线 + 「AI 判断」 |
| 原始材料 | 灰底 + 引用样式（引号缩进） |

**V2 判断三要素** —— 判断必须同时呈现，缺哪项显示"缺"，不留白：
- **依据**：可点，就地展开（不跳页）；显示条数与出处
- **不确定性**：`warning` 色文字，例如"性能与成本为对方自述，未经第三方验证"
- **什么时候成立**：`muted` 小字，含"尚未复核／标记待复核"

判断状态符号：`◇ 待核对` · `✓ 已确认` · `↩ 已被推翻`。

**V3 建议的四种状态** —— 各有固定形态：

| 状态 | 视觉 |
|---|---|
| 待你决定 | 左侧工作蓝细线 + 「AI 提议 · 等你决定」 |
| 已采纳 | `success` 点，可撤销 |
| 已改写 | 工作蓝点 + 显示改了什么 |
| 已否决 | 灰墨边、**卡片不消失**、显示你的理由与"不再推荐" |

**建议卡固定结构**：建议 → 依据 → 不确定性 → 四个回应（采纳为主色，改写/否决/稍后为次色或文字）→ 可展开的「为什么这么建议」。

## 9 · 关系与画布

- **实线**＝明确引用或用户确认；**虚线**＝AI 未确认判断。不得默认把推断当事实。
- 节点类型色点：项目蓝、任务绿、知识/记忆紫、事务赭、联系人/机构灰。
- **节点大小 = 连接度 + 层级**（2026-10-16 用户拍板补入）：项目（一组任务的容器）**大**、任务**小**；被多个对象引用的知识/议题**大**，孤立的小知识**小**。**大小只表达"它在关系网里的分量"，不表达重要/紧急** —— 重要和紧急是另外的字段，不靠大小表达。加成要有上限（当前实现：种类给底 + 连接数加成并封顶），免得个别节点膨胀成版面噪声。
- **按缩放分层**（强制）：<60% 名称 + 类型；60–110% 补状态与计数；>110% 才按需显示关系文字。
- 虚线旁边可轻确认（确认即变实线）；点连线显示画布内操作条（依据/忽略/撤销），不强制弹窗。
- 节点标题按宽度折行，最多两行 + 省略，全文进 `title` 与读屏标签；**不得溢出色块**。
- 画布必须保留：全局复位、查找聚焦、全屏、关系列表（等价阅读路径）。

## 10 · 分享与导出形态（V7）

- 可导出的判断必须**自带出处与时间**，以及"这是谁在什么时候的判断"。
- 导出前必须显示：**将分享 N 条 · 剔除 M 条仅自己**（把剔除的说出来，不静默少几条）。
- 每条判断默认「仅自己」；改成「可以给同事看」是逐条动作，不是全局开关。
- 文档形态沿用现有 document-cover / report-head；导出件不使用产品 UI 的交互组件。

## 11 · 无障碍与多端

- 正文/白底对比度 ≥ 4.5:1；关键边界与聚焦环 ≥ 3:1；浅色分隔线不做唯一输入边界。
- 焦点环 3px；Tab 顺序跟随视觉布局；焦点始终可见；弹窗关闭后焦点返回触发点。
- 真实按钮与表单标签；画布同时提供关系列表与节点名称。
- 状态变化用 `aria-live` 宣告；200% 放大下操作可达。
- `prefers-reduced-motion` 下所有动效即时完成。
- 断点：≥1200 全量 · 701–1199 双列 · ≤700 单列（导航折为顶部紧凑入口，保留全部入口）。
- 深色：走变量层 `[data-theme=dark]`；深色下全量逐文本节点对比度须 0 处不达标。

## 12 · 宿主主题（V6）

- 插件**必须消费宿主主题语义变量**，不自行发明一套主题映射。目标前缀为 `--dsw-alias-*`（来自既有审计记录）。**具体变量名必须在宿主实现中核实后写入本节**（核实方式：在真实页面枚举 `--dsw-*` 变量，或读取宿主主题样式表）。**核实之前不得声称"已消费宿主主题"。**
- **已核实（2026-10-16，用 Cordis Inspect 的 client Theme `listTokens` 枚举宿主当前主题）**，共 14 个，全部要求同时提供浅色与深色值：

  | 变量 | 用途 | 工作台接到哪 |
  |---|---|---|
  | `--dsw-alias-bg-base` | 应用底色 | `--ws-paper` |
  | `--dsw-alias-bg-layer-1` | 一级浮起面 | `--ws-surface` |
  | `--dsw-alias-bg-layer-2` | 二级嵌套面 | （暂未用：工作台没有嵌套面） |
  | `--dsw-alias-bg-overlay` | 浮层/弹窗底 | 弹窗底 |
  | `--dsw-alias-border-l1` | 一级细边 | `--ws-line` |
  | `--dsw-alias-border-l2` | 二级更强的边 | （暂未用） |
  | `--dsw-alias-brand-primary` | 品牌主色 | `--ws-action` |
  | `--dsw-alias-label-primary` | 主文字 | `--ws-ink` |
  | `--dsw-alias-label-secondary` | 次文字 | `--ws-muted` |
  | `--dsw-alias-state-error-primary` | 错误 | `--ws-danger` |
  | `--dsw-alias-state-success-primary` | 成功 | `--ws-success` |
  | `--dsw-alias-state-warn-primary` | 警告 | `--ws-warning` |
  | `--dsw-alias-state-idle-primary` | 非活跃 | （暂未用：工作台用 `--ws-muted` 表达） |
  | `--dsw-specific-sidebar-fill` | 侧栏底 | 侧栏底 |

- **落地写法**（实现见 `design-system/v7-host-theme.css`）：`--ws-x: var(--dsw-alias-y, <原值>)`。
  宿主在就跟随宿主主题（含深色）；宿主不在（独立预览页、门禁夹具）就保持原值，**视觉零漂移**。
  工作台自有的知识紫、数据配色与 `-soft` 派生色**不属宿主语义**，保持自有来源（登记在 `spec/registry.json`）。
- **禁止用 `!important` 覆盖**原型内联色（实现层现有 3 处须清理）。
- 迁移期允许保留 `--ws-*` 作为变量层，但最终色值来源必须是宿主语义变量 + tokens。
