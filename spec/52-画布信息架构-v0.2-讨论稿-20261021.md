## 0 · 定位先说清楚

**这是个人工作台的通用关联画布，不是天宽生态图，也不是某家公司的 BI。**

- 服务对象：任何使用工作台的人；他的机构、项目、任务、资料、判断与关系
- 分类：**用户自己定义**；分类名称、颜色、形状、顺序都可配置
- 天宽的一核四极：只是**一个示例预设/一份用户数据**，不是产品默认、不是产品 IA、不写进代码
- 产品文案：沿用「关联空间」「机构/项目/任务/关系」；**不用**「生态画布」「一核四极」「势能极/供给极/价值极/规则极」作为产品词
- 产品默认：没有分类也能用（全部进「未分类」）；有分类就按分类分组；不假设一定有一个「核心」

**结论**：画布不能只做成一棵树；结构用层级、关系用叠加、AI 推断单独一层。
分类不做一个「分类大框」，而是 **颜色 + 形状 + 名称** 三重编码；分类由用户配置，画布按分类分组。

## 2 · 分类模型：用户定义，天宽四极只是示例

### 2.1 数据与呈现分开

| 层 | 放什么 | 谁维护 |
|---|---|---|
| 业务数据 | `organization.category`：分类名称（自由文本，可空=未分类） | 用户改机构时填写 |
| 视图配置 | `layout:ecosystem.categories`：`label / color / shape / order / center?` | 用户在画布「分类设置」里调整；可导出/导入 |
| 示例预设 | 天宽四极：`势能极/供给极/价值极/规则极` + 可选「核心」 | 只在演示数据/用户导入中出现，**不进产品默认** |

- 不新增对象类型；分类是 organization 的字段 + layout 的视觉配置
- 分类名由用户输入；颜色从已登记调色板（`--pal-*` / `--series-*`）里选，形状只有 5 种
- 分类名唯一事实源是 `organization.category`；layout 的 `label` 只做查表键，不出现第二份分类名；分类设置只改颜色/形状/顺序，不改名
- 未配置颜色/形状时，按分类出现顺序自动分配；**不写库**
- 分类数量：建议 ≤10；超过时多出的进「其他」，不硬塞颜色

### 2.2 视觉编码

- 每个分类：颜色 + 形状 + 名称；机构卡左侧 3px 色条 + 形状徽标 + 分类名
- 颜色不得单独承担区分；图例可切换「颜色+形状 / 只看颜色 / 只看形状」用于验收
- 未分类：灰 + 问号形状 + 「未分类」
- 不假设「核心」；如果用户把某个分类设为 `center`，可切「中心+外围」模板；否则默认「分组列」

### 2.3 天宽四极示例（只作演示数据）

| 示例分类 | 颜色 | 形状 | 说明 |
|---|---|---|---|
| 核心（可选） | `--ws-ink` | 六边形 | 示例：天宽本体 |
| 势能极 | `--pal-gold` | 菱形 | 示例：智源、鹏城、南网、杭州人工智能中心 |
| 供给极 | `--pal-indigo` | 方形 | 示例：昇腾、沐曦、摩尔线程、璧仞、海光、寒武纪、微纳核芯 |
| 价值极 | `--pal-teal` | 圆形 | 示例：智谱、Kimi、DeepSeek、世界模型厂商、具身智能厂商 |
| 规则极 | `--pal-violet` | 三角 | 示例：GCC、CCSA、AIIA、ODCC、信通院、IEEE/ITU |

> 这张表是**演示数据**，不是产品默认；产品默认没有这些词。

## 3 · 层级与交互（与 v0.1 相同）

| 层 | 画布上 | 单击 | 双击 | 弹窗 |
|---|---|---|---|---|
| 机构 | 分类色条 + 形状徽标 + 名称 + 项目数 | 下钻 | 机构详情 | 分类、说明、联系人、项目 |
| 项目 | 主责机构下的项目卡 | 展开任务 | 项目详情 | 目标、时间、任务、资料 |
| 任务 | 项目下的任务卡 | 高亮 | 任务详情 | 预期成果、依赖 |
| 资料/判断/事务 | 不进主层 | — | — | 项目详情/关系态 |

- 一个项目一个主责机构；其余为参与机构，走关系
- 未归属项目单列一桶，不猜
- 下钻 + 面包屑 + Esc 回退；不把四极全展开

## 4 · 弹窗编辑：只保存改动（与 v0.1 相同）

- 居中弹窗；字段缓冲；底部「将改 N 项」；只写改动字段；保存后撤销
- 单字段快速改保留（现有 inline）
- 未保存关闭先提示；走既有版本校验/撤销

## 5 · AI 边界（与 v0.1 相同）

- 候选必须带依据/不确定性/为什么现在提
- 同意才实线；不同意不复活；对象/依据变了标待复核
- 节点间都能连，但**不能只凭同一分类**提关系
- AI 不改结构/不自动分配主责机构

## 7 · 数据模型（落地时）

1. `organization.category`：自由文本（可空=未分类）；校验长度/去空
2. `layout:ecosystem.categories`：`[{label,color,shape,order,center?}]`；颜色/形状只认登记值；≤10
3. `project.organizationId`：主责机构（可空=未归属）；保留 `partnerId`
4. `organization.contactId/note`、`person.note`：修现有校验缺口
5. `relation`：**不加 type 枚举**；title + evidence
6. `layout:ecosystem` 与旧 `view:'space'` 分开；缩放不自动写
7. 产品代码不含天宽/四极词；示例只放 `spec/`、演示、测试夹具

---

## 8 · 待拍板

1. **分类模型**：A 自由文本 + layout 视觉配置（建议，不新增对象类型）；B 新增 taxonomy 对象（更重、可分享）；C 固定通用枚举（最轻、最不灵活）
2. **项目主责机构**：外部机构 / 内部业务单元 / 按类型分（建议按类型）
3. **体外公司**：组织 / 项目 / 先项目（建议先项目）
4. **机构视觉**：整卡分类色（需改 VI §9）/ 色条+形状（建议）
5. **数据准备**：先 dry-run 清单确认 / 直接建 / 暂不建
6. **模板**：默认分组列；要不要保留「中心+外围」作为可选模板（演示那种）
