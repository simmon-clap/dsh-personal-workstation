## 1 · 判断：一条判断能不能追回出处（宪章判据 3、6）

| 做什么 | 应该看到 |
|---|---|
| 知识 → **研究议题** → 点开一条判断 | 详情里有「**依据（N 条）**」；还有「不确定性」 |
| 看依据那一行 | 有「**看原始出处**」按钮（网页类是「打开网页」；口述类会写"没有出处文件可点"） |
| 点「看原始出处」 | **直接打开那份材料**（不再先把你丢到文件列表里自己找） |
| 如果那份材料是**录音** | 打开的是**播放器**；依据里写了第几秒就**跳到那一段**，并写明「已跳到 X 分 Y 秒」 |
| 如果依据写的秒数**比录音还长** | 会**说实话**：「这个出处写的是第 8 秒，可这段录音只有 5 秒 —— 已经停在录音的结尾。」（不许谎称"已跳到"） |
| 点「**编辑**」→ **只改标题** → 保存 → 再看依据 | 依据**还在**，出处**没丢**（这条以前是坏的：改一次判断，文件/录音出处全没了） |
| 回列表页点「**导出**」 | 先弹一行「**将分享 N 条 · 剔除 M 条仅自己（共 K 条判断）**」，再下载一份 .md |
| 打开那份 .md | 写的是**中文**（"录音"、"尚未经过第三方验证"），**不会出现** `art-xxxx` 这种内部编号；带秒数的会写成「（第 120–180 秒）」 |

## 2 · 收件箱：AI 提议与"不同意不复活"（批次 C/E）

| 做什么 | 应该看到 |
|---|---|
| 打开 **收件箱** | 目前是 **0 条待决定**（我把之前那 4 条垃圾批次撤了） |
| 若有 AI 提议卡片 | 卡片上写着「**AI 提议 · 等你决定**」，左侧有蓝色细线（不是只靠颜色区分） |
| 卡片上有四个按钮：**采纳 / 改写 / 否决 / 稍后**；点「否决」会要你留一句话（写清为什么不同意） | 记下理由后那条**不会自己回来**（否决要留痕、不复活） |
| 画布上，AI 推的连线 | **紫色 + 虚线 + 写着「AI 判断」**三样齐全；点它能看到**依据**；可以**否决** |

## 3 · 无限画布：缩放分层（VI §9）

| 做什么 | 应该看到 |
|---|---|
| 画布上连点几次「−」（缩到很小，约 <60%） | 节点只剩**名称 + 类型**；**关系文字消失** |

| 拖动画布 | 平移时不该闪烁重绘（只有缩放才重绘） |

## 我这边已经替你跑过的（不用你重复）

| 项 | 命令 | 结果 |
|---|---|---|
| 全部单元测试 | `npm test` | **674 项全过** |
| 全部门禁（含真实浏览器） | `npm run verify` | **35 道 · EXIT=0** |
| **全部真实数据验收**（判据 1/2/3/4/5 + 真机版本） | **`npm run accept`** | **5 项全 PASS**（2026-10-17 18:21 重启后实测） |
| ↳ 不想用实例时（不需要登录态） | `npm run accept:no-instance` | **4 项全 PASS** |
| "看到的=装的"（门禁在 verify 链尾） | `npm run verify` 里的 `release-check` | PASS |

> `npm run accept` 是这一轮新加的：它把五个真实数据验收**串成一条命令**，逐个跑、不互相掩盖，
> 最后给一张总表；任何一项不过就非零退出。
> **为什么不能只跑 `verify`**：verify 里的 35 道门禁全跑在**内存夹具**上 —— 能证明"UI 逻辑对"，
> 证明不了"真实数据里发生过"。宪章六条判据里有五条要的正是后者。
