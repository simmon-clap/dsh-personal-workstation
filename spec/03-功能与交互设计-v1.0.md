## 0 · 判据

每个功能与交互都必须同时满足三条，缺一不成立：

1. **可推导** —— 能指出它服务宪章哪一条。指不出来的不做。
2. **不违背品味** —— 实现方式符合第六条（诚实/安静/克制/有重量/耐用/精致）。
3. **有视觉语言** —— 新概念在 VI 里有对应表达，不靠临时发挥。

### 十二条之外 · 就地编辑（2026-10-15 补，用户要求）

**这一条是交互律 01「人只在分叉点出现」在字段上的直接推论，用户明确要求后补入规范。**

> 用户原话：「项目页打开后，单击对应模块都是可以直接进行编辑的，包括文本、时间、负责人」；
> 「项目和任务在直接单击可编辑上我认为应该是一样的」。

**规则**

| 判据 | 要求 |
| --- | --- |
| 触发 | **单击值本身**进入编辑，不需要先点「编辑」按钮 |
| 生效 | **即时生效 + 左下「已保存 · 撤销」**（契约②）。不弹确认、不进收件箱 |
| 控件 | 全站**同一个**就地编辑控件；进入编辑后换成与表单一致的字段样式（36 高、圆角 8、焦点环 3px） |
| 外观 | 值是**可点的文字**，不是按钮样子 —— 免得一屏几十个按钮感（克制）。虚线暗示可编辑 |
| 空值 | 如实写「未设置」，**不用颜色表示"空"**（VI §2） |
| 退出 | Escape 还原、失焦还原；未改动就什么都不发生 |
| **关系的边界** | **关系型字段（依赖任务、关联材料）不做成就地可编辑** —— 改它们走各自的动作（"关联已有材料"）。做一个改不了关系的假可编辑，比不做更坏 |
| **未接入的边界** | 字段本身可以填，但若它依赖**未接通的**能力（如「执行端」依赖任务执行器），旁边必须写明「只记录意向」（约束三：未接入不伪造） |

**为什么不与「编辑」弹窗重复**：弹窗留给"一次改很多字段"；改一个字段用它。用户 2026-10-15 拍板选即时生效，不做"改完统一保存"。

## 4 · 状态语言（六种，固定说法与固定样子）

| 状态 | 样子 | 说法 | 下一步 |
|---|---|---|---|
| 进行中 | 骨架保留布局；超 1 秒才提示 | 不显示假百分比 | 取消或返回 |
| 已完成 | 绿点 + 文字 | 有真实回执才说"已保存" | 左下常驻撤销 |
| 等待 | 赭色文字，写明等谁/等什么 | 没写原因就"原因未记录" | 指向补什么 |
| 失败 | 一句人话 + 一个可点下一步 | 保留内容、说明所缺 | 重试/换位置/看差异 |
| 未接入 | 灰字说明，不给假按钮 | "这个能力还没接上" | 无 |
| 推断 · 待核对 | 紫 + 虚线 + 「AI 判断」 | 区分"对方自述""未经第三方验证" | 确认/忽略/撤销 |

## 5 · 关键流程

**A · 一条判断的一生**：材料进来 → Agent 整理出候选 → 你确认或改写 → 进入议题/项目 → 被新证据推翻 → 旧判断留痕（↩ 已被推翻 · 原因 · 日期）。依据就地展开。

**B · 一条建议的闭环**：AI 提议进收件箱 → 卡上四选一 → 改写/否决就地写一行理由 → 记入你的判断与理由 → 下次建议带上原因。**否决后卡片不消失**，转灰墨留在原位。

**C · 核对**：判断里标"对方自述" → 汇总到待核对筛选视图 → 你勾选核对 → 改写该条的不确定性说明。不设新入口、不推送、不计逾期。

**D · 分享**：选中判断 → 导出 → 预览"将分享 N 条 · 剔除 M 条仅自己" → 导出带出处与时间的文档。

**E · 心跳**：按时醒来 → 做事（守承诺/盯依赖/做简报/复核旧判断）→ 按额度和条件判定是否出声 → 合并同一时段的事 → 在你能处理的时刻送达 → 留痕。

**不打断清单**：录入/粘贴/传文件/转写（不打断）· 整理/识别/检索/生成候选（不打断）· 预览/展开依据/看历史（不打断）· 自己的新建编辑改归属（轻反馈 + 可撤销）· 删除归档写日历对外发送（停住）· AI 提议（进收件箱）· 硬规则（当场问）。

## 6 · 克制与主动的平衡机制

**核心判断**：注意力不是可以平均分配的配额。两种代价不对称 —— **多说的代价累积且不可逆**（第十次之后你不再读它），**漏说的代价单次但可能很大**。

**四句话**：**克制是默认，主动是挣来的，委托是例外，漏报是刹车。**

**① 出声额度由你的反馈决定，不由设计者拍**

| 你做了什么 | 额度 |
|---|---|
| 它出声、你照着做了 | 明显上升（最强信号） |
| 你回"知道了" | 小幅上升（弱信号） |
| 你说"这周别再提醒我" | 下降 |
| 你直接忽略 | 小幅下降（沉默也是投票） |
| 它长时间不出声 | **不变**（不允许靠"憋着"涨额度） |

额度不是"次数上限"，而是**它判断"值不值得找你"时的严格程度**。

**② 三扇门分开调节**

| 门 | 含义 | 默认 |
|---|---|---|
| 一 · 它盯多少 | 关注多少项目/机构/议题；调大只让它做得更多，不会更吵 | 所有活跃项目 + 你标过的议题 |
| 二 · 多少事值得找你 | 这才是音量 | **默认最小**（只有"错过就没了的事"） |
| 三 · 你让我盯的 | 你明确说过"这事盯着" | 无委托；**不受额度限制** |

> **你委托的，一定出声；它自己猜的，严格限量。委托优先于推断。**

**③ 出声四级**

| 级别 | 条件 | 形式 |
|---|---|---|
| 二级 · 一条消息（唯一能打断你的级别） | 同时满足：① 与你**明确承诺过**的事直接相关且到期/被阻塞；② 有**新的可核对事实**；③ 同类此前**没出过声** | 飞书一条消息，**必须写明"为什么现在告诉你"** |
| 一级 · 排在最前 | 建议、候选关系、可核对项、简报 | 不推送，打开时排在前面 |
| 零级 · 静默 | 一般更新、兴趣类信息、无来源推断 | 只进收件箱存档 |
| 永不出声 | 无来源内容、兴趣类简报、重复提醒、已否决建议 | — |

**④ 时机规则**：不打断等接缝 · **合并，不零散**（同一时段合成一条）· 在你处理的时刻（会前 30 分钟优于凌晨）· 免打扰窗口内只排序不出声 · **不重复不升级**（你没理就降级，不催）· **沉默也留痕**。

**⑤ 双向计量**：既要记"说多了"（你说没必要/忽略的比例），也要记**"该说没说"**（你事后标记，用于放宽条件）。**后者是防止系统为安静而变得没用的反向刹车。**

**⑥ 权限是挣来的**：陌生期（只有"错过就没了"出声）→ 试用期（你确认有用的类别解锁）→ 信任期（可更早提醒，仍需合并）；可接受率下降 → **自动回退**；任何阶段委托直接最高级。

**⑦ 心跳的诚实约束**：必须留痕 · **假死最危险**（最后成功时间可见、连续失败告警 —— 这是唯一允许的打扰例外）· 简报必须带来源与抓取时间 · 不产出无来源的判断。

**⑧ 复用宿主调度**：DSH 自带 `@deepseek-ai/dsh-schedule`（宿主级持久提醒 + 回到原会话投递）、`dsh-client-ui-schedule`、`dsh-experimental-schedule-bundle`（含时间上下文）。**不需要自建调度器。**需核实：能否作为 Service 消费、常驻 profile 下是否持久、审批如何对接。

**⑨ 三问判据（v1.1 补，2026-10-21）**：每一条出声必须回答三问——**变了什么**（事实）、**对你意味着什么**（判断）、**现在能做什么**（动作）。

- 缺第 3 问 = **通知**（只告诉你，不帮你办）；
- 缺第 2 问 = **播报**（信息，不是建议）；
- 三问齐 = **建议**。

**不说的必须写理由**（进 F24 留痕）。写不出理由 = 没判断过，等于噪音。这条同时是"收敛度"可被检验的地方：出声数 / 候选数、有用 / 出声。

## 7 · 概念审计（禁造词）

**判据**：能不能不解释就懂。**不得新增概念**；新能力一律复用已有动词（看/改/删/采纳/否决/稍后/导出）。

| 禁用的自造词 | 改用 |
|---|---|
| 倒推链 / 可倒推 | 为什么这么建议 |
| 契合度 | 最近的建议你采纳了多少 |
| 时效 | 什么时候成立 |
| 结论流 / 生命周期 / 能力域 | 你的判断与理由 / **六组能力**（文档用词，不进界面） |
| 分享边界 | 仅自己 / 可以给同事看 |
| 乐观 UI | 无回执的假成功 |

**表中带"（文档用词）"标注的，只在界面禁用，文档中可以引用；其余为彻底禁用。**

**四道直觉测试**（新功能必过）：一句话测试 · 母语测试 · 不解释测试 · 十年测试。**任一道不过，改词，而不是加说明。**

## 9 · 验收判据

1. 判断能落地：会议材料进来后，能沉淀出带依据、不确定性、什么时候成立的判断，并能在三个月后被检索到、被推翻且留痕。
2. 建议闭环可验证：一条建议能被采纳/改写/否决，否决理由被记住，下次建议可展开"为什么这么建议"，无支撑时自曝是通用建议。
3. 出声可控：二级出声同时满足三条件；额度随反馈涨落；免打扰窗口内零出声；每周你标记"没必要"的比例可查。
4. 反向刹车有效：能标记"该说没说"，且标记后该类条件确实放宽。
5. 丝滑可验：零跳页（依据就地展开）、零等待感（点击立刻响应）、零学习（无新造词）。
6. 精致可验：VI 门禁 12 项全绿。
7. 概念零新增：界面词汇全部在册，四道直觉测试全过。
8. 未接入不伪造：能力状态与实际一致。
9. **十年测试**：十年后打开，能回答"我认识谁、承诺过什么、当时为什么这么判断" —— 机构、承诺、判断三类对象都能一路点回原始出处。
10. **可迁移**：数据可整体导出且格式开放（不依赖插件运行）；替换模型与 Agent 后，事实与治理不重来（用一次真实替换验证）。

## 10 · 判断的数据契约（批次 1 开工必需）

对象类型 `judgment`（判断）。**批次 1 实现之前不得在界面或工具里使用。**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | 稳定 ID | 是 | 沿用既有对象 ID 规则 |
| `title` | 文本 | 是 | 判断陈述，1–200 字 |
| `evidence` | 数组 | 是（≥1 项） | 每项 `{ kind, ref, quote, verified }`：`kind` ∈ 会话原文／文件／录音片段／网页／你的口述；`ref` 为引用锚点（见下）；`quote` 出处文字 ≤300 字；`verified` 是否经第三方验证 |
| `uncertainty` | 文本 | 否（≤300 字） | 未验证部分、对方自述等；为空时界面显示"未标不确定性" |
| `validFrom` | 日期 / ISO | 是 | 什么时候成立 |
| `reviewBy` | 日期 | 否 | 何时该复核（批次 8 的"复核旧判断"用） |
| `status` | 枚举 | 是 | `current` 当前有效 / `checking` 待核对 / `overturned` 已被推翻 |
| `overturnedBy` | 引用 + 文本 + 时间 | 条件必填 | `status=overturned` 时必填：新证据或新判断的引用、推翻理由 ≤300 字、时间 |
| `projectId` / `sourceRefs` / `sources` | 引用 | 否 | 沿用通用字段与字段来源口径 |

**格式与必填约束**：`evidence` 至少 1 项；`status=overturned` 必须有 `overturnedBy`；`validFrom` 不得晚于创建时间；`uncertainty` 与 `quote` 不接受空字符串。

**引用锚点（`ref`）格式**：会话原文 → 消息 ID；文件 → `path` + `fileVersion`；录音 → 文件 + 时间区间（秒）；网页 → URL（**未抓取正文时不得声称已读**，与既有口径一致）。

## 11 · 出声额度：可调初值（批次 8 开工必需）

> 以下数值是为了让验收**可测**而给的**可调初值**，不是我的定论。上线后按你实际的被打扰感调整。

- **额度**用 0–100 分表示，**初值 40**。
- **上调**：你照着做了 +8；回"知道了" +2。
- **下调**：你说"这周别再提醒我" −10；你直接忽略 −3。
- **阶段与门槛**：<30 陌生期（只允许"错过就没了的事"出声）；30–69 试用期（允许承诺到期与依赖解锁，同类每周一次）；≥70 信任期（允许更早提醒）。
- **二级出声每周上限** = `1 + 额度 // 25`（40 → 2 次，70 → 3 次，100 → 5 次）。
- **免打扰窗口**：默认 22:00–08:00 加周末；窗口内一律降为一级/零级。
- **同时最多委托 5 件**；超出时新委托进入等待，不静默丢弃。
- **"该说没说"**：你标记后，该类条件的门槛下调一档（例如从"须有承诺"降到"须有明确议题关联"）。

**飞书出声的前提**：复用 IM 助理渠道（第三方插件 `@michengai/dsh-im-connect`）。**工作台当前没有发送代码，接口与载荷须核实**；核实完成前，二级出声降级为一级，不得声称"已能推送"。

## 12 · 出声级别的命名澄清

"出声四级"实为**三档可达级别 + 一类永不出声**：二级（能打断你）· 一级（只排序）· 零级（只存档）· 永不出声（禁止类）。文中"四级"即此四类。

## 13 · 入口矩阵与三本账（v1.1 补，2026-10-21）

**从宪章推**：第二条「事事有回应」——**不漏的前提是每个入口都有承接方**。

| 入口 | 怎么进来 | 谁接住 | 接住后第一件事 |
|---|---|---|---|
| 工作台页面 | 打字 / 粘贴 | 收件本 | 认归属：哪个项目、哪个人 |
| DSH 对话 | 对话里说 | 收件本 | 认归属；能直接落下就立刻落下 |
| 飞书 IM | 发给助理 | 收件本 | 认归属；回一句「记下了」 |
| 语音 | 录音转文字 | 收件本 | 认归属 |
| 日程 / 日历 | 只读同步 | 着落本 | 看有没有撞车、有没有到期 |
| 邮件 | 只读连接器 | 收件本 | 只记「有一条在等你」，不存正文 |
| 资料 / 文件 | 导入或授权目录 | 着落本 | 看是不是新证据 |
| 健康 | 只读 | 着落本 | 今天扛不扛得住 |
| 它自己 | 定时醒来 | 心跳本 | 看有没有东西到期、没人管 |

**三本账**（运行记录，与 `heartbeat_runs` 同类；**不是业务对象**，不进画布、不进收件箱对象列表）：

| 账本 | 记什么 | 不记什么 |
|---|---|---|
| 收件本 | 今天收到什么、谁接的、现在什么状态 | 正文（只记引用） |
| 着落本 | 每件事最后去哪了：完成 / 放弃 / 转出 / 在等谁到何时 | 过程细节 |
| 心跳本 | 每次醒来：看到几件、说没说、为什么 | 无依据的推断 |

**三条硬约束**

1. **每条输入必须落一行**，状态三选一：记下了 / 不用你管 / 需要你一句话。**没有"处理中"的黑洞。**
2. **不说的必须写理由**（复用 §6 ⑨）。
3. **归不上就写"未归属"，不猜**（F3）。

**不做**：不复制外部正文（日历/邮件只记引用）；不动任何现有表结构；助理只读业务对象，要改走「提议 → 收件箱 → 你点头」（宪章第五条）。
