## 0 · 定位先说清楚

**这是个人工作台的通用关联画布，不是天宽生态图，也不是任何一家公司的 BI。**

| 不许偏移的 | 具体做法 |
|---|---|
| 不写死天宽 | 产品代码/默认分类/默认文案里不出现「天宽、势能极、供给极、价值极、规则极、一核四极、生态画布」；这些只出现在演示数据、`spec/` 文档、测试夹具 |
| 分类是用户的 | `organization.category` 是自由文本；颜色/形状/顺序由用户在画布「分类设置」里配；没有分类也能用（全部进「未分类」） |
| 不假设有「核心」 | 默认模板是「分组列」；只有用户把某分类标成 `center` 才出现「中心+外围」模板 |
| 不照搬演示外壳 | 产品用现有「关联空间」画布与工具条；演示页的 Paper Glass 顶栏只是设计参照 |
| 演示要标注 | 演示页明确写「示例预设，可替换」；不把演示当产品默认/真实数据 |

**一句话**：画布解决「机构→项目→任务 + 关系」的通用问题；天宽四极只是这个通用能力的一个实例。

## 2 · 分类模型：用户定义，四极只是示例

### 2.1 数据与呈现分开

| 层 | 放什么 | 谁维护 |
|---|---|---|
| 业务数据 | `organization.category`：分类名称（自由文本；空=未分类） | 用户改机构时填 |
| 视图配置 | `layout:ecosystem.categories`：`label / color / shape / order / center?` | 用户在画布「分类设置」里调；可导出/导入 |
| 示例 | 天宽四极（势能/供给/价值/规则 + 可选核心） | 只在演示数据/用户手动配置里；**不进产品默认** |

- 推荐**不新增对象类型**：分类名是 organization 字段，颜色/形状/顺序是 layout 的视图配置
- 颜色只从已登记调色板取（`--pal-*` / `--series-*`）；形状只有 5 种；≤10 类；不写 hex
- 未配置映射时按分类出现顺序自动配色/形状；**不写库**；用户改过才落 layout
- 分类设置入口只放**一个**（图例/更多二者选一），**不新增一级入口**；分类名唯一事实源是 `organization.category`，`layout.categories.label` 只做查表键，不显示为第二份分类名；设置只改颜色/形状/顺序，不改名

### 2.2 视觉编码

- 颜色 + 形状 + 名称三重编码；机构卡用左侧 3px 分类色条 + 形状徽标 + 分类名
- 颜色不得单独承担区分；图例可切「颜色+形状 / 只看颜色 / 只看形状」用于验收
- 未分类：灰 + 问号形状 + 「未分类」；未归属项目：单独一桶 + 「未归属」
- 不假设「核心」；`center` 只是可选配置
- 节点大小：项目视觉面积 > 任务；连接度加成封顶（VI §9）

## 6 · 目标形态

### 6.1 三态（同一画布，不新增入口）

| 态 | 默认 | 内容 |
|---|---|---|
| 结构 | 是 | 分类分组 → 机构 → 项目 → 任务；资料/判断/事务不进主层 |
| 关系 | 否 | 现有全部关系/跨项目共享/AI 建议筛选+搜索；邻接聚焦 |
| 待确认 | 否 | 只显示 AI 建议；一次一条；操作条同意/不同意/稍后 |

### 6.2 分类与模板

- 分类来自 `organization.category`；有分类就分组，没有就全部「未分类」
- 分类设置：从图例/更多打开；调色/形状/顺序；≤10；不新增入口
- 模板：`columns` 默认（每分类一列，机构竖排）；`radial` 可选（某分类 `center`，其余环绕）；演示款只是 radial 的一个实例
- 两轴/三步骤：**只在演示里作注释**，不是产品能力；产品不画死

### 6.3 层级与交互

- 机构→项目→任务；单击下钻，双击详情，面包屑/Esc 回退
- 项目卡：阶段/负责人/截止/任务数；任务卡：状态/负责人/截止
- 未归属项目单列；点击可指定机构
- 关系态：点节点邻接聚焦；点连线出操作条（CV-08）

### 6.4 弹窗编辑（只存改动）

- 居中弹窗；「编辑」进入批量缓冲；底部「将改 N 项：旧值 → 新值」
- 「改这 N 项」一次提交；未改字段不写；保存后「已改 · 撤销」
- 单字段快速改保留；未保存关闭先提示；版本冲突重放自己的字段改动

### 6.5 AI 关系

- 候选必须有对象/标题/依据/不确定性/为什么现在提
- 白名单组合（同项目/同会议/同材料/同专名/共同参与）；**不能只凭同一分类**
- 虚线 + 「AI 判断」；点击操作条；同意才实线；拒绝不复活；对象/依据变化标待复核
- 支持跨层；不自动改机构归属

## 7 · 数据模型与兼容

| 对象/位置 | 字段 | 规则 | 兼容 |
|---|---|---|---|
| organization | `category` | 自由文本；trim；≤40 字；可空=未分类 | 旧数据不改；未分类桶 |
| organization | `contactId` / `note` | 引用 person / 文本 | 修现存校验缺口 |
| project | `organizationId` | 引用 organization；可空=未归属；≤1 | 保留 `partnerId`；不自动迁移 |
| person | `note` | 文本 | 修现存校验缺口 |
| layout:ecosystem | `categories` | `[{label,color,shape,order,center?}]`；≤10；color 只认调色板名；shape 5 种 | 新 view，与旧 `view:'space'` 分开 |
| layout:ecosystem | `template` | `columns`/`radial` | 默认 columns |
| relation | 不加 type | title + evidence | 无迁移 |

**数据准备（C1，全部 batch）**

1. `.backup` 真实库
2. dry-run：`TK` → 建议改名「天宽」+ 分类「核心/未分类」（D5 确认）；2 个项目主责机构建议
3. 按截图建机构：**只在 D5 确认后**；来源标注「用户提供的生态结构图」；不写虚构联系人
4. v1 不支持改分类名（改名=批量更新组织分类，另批）；layout 映射按分类名匹配，改名后旧映射显示「未分类」，不静默乱配
5. 未确认项目保持 `organizationId` 空 → 「未归属」；不自动挂
6. 迁移可撤销；回滚用批次回执/备份
